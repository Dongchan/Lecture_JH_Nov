2026. 11. 11. · 박동찬 · 한국직업능력연구원

- 브라우저에서 위 주소를 열고 → ← 방향키나 Space로 장을 넘깁니다. `#숫자`를 주소 뒤에 붙이면 그 장으로 바로 갑니다.
- 오른쪽 아래 버튼이나 F 키로 전체 화면을 켜고 끕니다. 아이폰은 웹 페이지 전체 화면이 안 되므로, 공유 버튼 → '홈 화면에 추가'로 만든 아이콘으로 열면 주소창 없이 보입니다.
- 시연 영상이 든 장은 '영상 보기' 버튼이나 V 키로 재생합니다.
- 그림이 든 장은 그림을 클릭하거나 Z 키로 원본을 크게 봅니다(Esc로 닫음).
